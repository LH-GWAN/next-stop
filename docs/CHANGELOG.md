## 2026-09-26 — TourAPI 매뉴얼 반영, TMAP 없이 실데이터 빌드

- TourAPI 매뉴얼(api.visitkorea.or.kr)과 대조: 오퍼레이션, `detailIntro2` 영업 필드는 일치. KorService2는 `cat1~3`을 비우고 분류체계 `lclsSystm1~3`을 주므로 `lclsSystmCode2`로 코드표를 받아 범주 판단에 씀(장소명 키워드 보조)
- TMAP 키가 없으면 빌드를 멈추지 않고 직선거리 추정값을 씀(`travel_source: "estimate"`, `travel_mode`). 화면은 이동시간에 `약`, 카드에 "직선거리로 추정", 푸터에 "TMAP API 키가 필요합니다"
- 테스트 추가: 범주 판단 5개, TMAP 없는 실데이터 빌드 1개 (Python 43개)
